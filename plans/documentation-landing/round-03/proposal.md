# CtxFerry landing

Developers can run the native desktop from source, use the CLI, or learn how to share selected records through their private GitHub repository. The setup choices are followed by a worked example of the Home attention model and guides to Projects, Catalog and Sync.

Inspect the complete desktop.png (1440 CSS pixels wide) and mobile.png (390). Home is a complete production window from the isolated atlas-api example on legion-pc. Its three counts are printed beside the image for reading at any width. The image and Full-size image open the original, while Inspect the queue opens the relevant guide. Production capture provenance is in docs/development/desktop/review-native-redesign.md. Functional references are docs/content/desktop.md and plans/desktop-information-architecture.md.

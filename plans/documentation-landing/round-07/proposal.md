# CtxFerry landing

Visitors can start the native desktop from source, follow the CLI quickstart, or open the private sync guide. The interactive example shows atlas-api on legion-pc. Conflict and Device use the original Home window, while Project opens the original Project overview. Each selected screenshot detail is outlined in its matching complete window. Native-resolution excerpts show the queue tile, the selected checkout row, or the sync service and commit observations. Only the explicit guide links navigate from a detail; Open original and the complete window link to the corresponding full capture. Selectable text preserves both full paths on narrow screens.

Review desktop.png and mobile.png as the complete Conflict pages; desktop-project.png, mobile-project.png, desktop-device.png and mobile-device.png are the other states of the explorer at both widths. The synthetic workspace and real native capture are documented in docs/development/desktop/review-native-redesign.md. See docs/content/desktop.md and plans/desktop-information-architecture.md for functions and flows.

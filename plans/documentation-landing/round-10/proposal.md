# CtxFerry documentation landing

The landing offers native desktop setup, CLI setup, private GitHub sync and direct guide navigation. The example follows the atlas-api Project on legion-pc through three running-app captures. Conflict shows the selected Deployment runbook and its Conflict badge in Sync → Queue. Project shows checkout-b and its saved staging Profile. Device shows the unavailable service and the last confirmed commit in Home. The inspector quotes the corresponding outlined region and places a separate guide link underneath.

Actual size displays the native image at 1280 × 800, centered on the selected region. Pan using touch, a trackpad or the focused viewport’s arrow keys. A status strip indicates the current mode. At phone widths the enlarged window takes the place of the secondary excerpt in this mode. Open original provides the complete PNG.

Desktop and mobile each have four frames: the full default Conflict page, the Project and Device states, and the actual-size Conflict view. See docs/content/desktop.md, plans/desktop-information-architecture.md and docs/development/desktop/review-native-redesign.md for functional and capture context.

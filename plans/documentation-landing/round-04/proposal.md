# CtxFerry landing

The primary actions lead to the native source setup and the CLI quickstart. The hero links directly to private sync. Projects, Catalog and Sync guide cards use the same destinations as the native application.

Review the complete desktop.png (1440 CSS pixels wide) and mobile.png (390). The worked example is the atlas-api project on legion-pc, with one conflicting record, zero waiting and zero blocked. “Read the queue guide” opens the documentation for Sync. The desktop figure shows the complete native window. On mobile, “Home screenshot details” displays three excerpts of that same PNG at reading size: the conflict tile, the project identifier and the device observation. “Full window” opens the original image at either width. The source state and capture revision are in docs/development/desktop/review-native-redesign.md; functional scope is in docs/content/desktop.md and plans/desktop-information-architecture.md.

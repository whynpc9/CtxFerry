# 设备总览与同步页的实机截图评审

初版实现 `03c178e`，Kimi K3.1 Pro（Thinking Max）逐张评审了 macOS 上同一隔离工作区的总览与同步截图。该工作区已绑定一个项目，尚未配置远端。七项原始分依次为排版 8.0、层级 7.5、间距与密度 7.0、色彩与对比 7.5、图标 6.5、一致性与完成度 7.0、清晰度 5.5，均值 7.0。初版图保存在该提交的 `docs/desktop/screenshots/`。

## 修订及复核材料

实现 `1e4f6c1` 的设备总览和同步页截图归档在提交 `c7d92ad` 的 `docs/desktop/screenshots/`。两张图均为桌面采集后转换的 2360 × 1500 PNG。

| 初审发现 | 处理与证据 |
|---|---|
| 无仓库时，明文说明容易被理解为仓库已通过隐私核验 | 同步页说明发布前核验与发布后的明文边界，并将远端确认标为不适用。 |
| 无法区分空队列与没有查询，且缺少连接入口说明 | 核心在同一个只读事务里查询本机队列与冲突，成功读取后才展示数量。同步页给出连接专用私有库的 CLI 示例与刷新步骤。 |
| 未检查认证的原因不清楚 | 总览将 Git 未配置远端与桌面快照未查询 Infisical、Bitwarden 登录状态分开。 |
| 左上角未见系统窗口控件 | Terra 通过 macOS 辅助功能树定位到关闭、最小化和全屏控件，实测最小化、恢复、缩放并关闭了测试进程。系统截图接口取图失败，采集标记遮挡标题栏局部，按钮外观与标题栏拖动仍待确认。 |

上述截图拍摄时只绑定了 `smoke-28`。拍摄后通过 CLI 绑定第二个项目，在窗口内点击刷新，辅助功能树出现了新项目。当前截图证据覆盖未配置远端的 macOS 窗口；已配置仓库的数据展示以及小窗口、读屏等场景仍需各自的证据。
